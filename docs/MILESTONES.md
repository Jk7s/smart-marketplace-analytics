# Suggested six milestone releases

1. **M1 — Baseline:** seeded catalogue, exact scan, correctness checks, cost-model trace.
2. **M2 — Query and history:** price/category filters, substring-capable keyword search, product versions.
3. **M3 — Compact summaries and duplicates:** approximate unique count, percentiles, duplicate candidates.
4. **M4 — Vector retrieval:** deterministic product/query vectors, keyword/vector/hybrid modes, reranking.
5. **M5 — Streaming analytics:** seeded event replay, time windows, event totals, unique visitors.
6. **M6 — Integration:** version-aware refresh workflow, shard/replica simulation, tests, benchmark evidence, README.

For each release, capture the relevant page, run tests, record expected versus observed output, and write a short individual explanation.
